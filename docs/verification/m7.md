# M7 verification report

Evidence Sufficiency Gate and provider-independent grounded generation.

**A grounded draft is NOT yet claim-verified.** M7 checks that a draft's every citation names an
evidence block that was actually supplied to it. It does not check that the cited block supports
the sentence. That is M8, and until it exists a draft is typed
`UNVERIFIED_AWAITING_CLAIM_VERIFICATION` and no response shape can present it as an answer.
`answering_enabled` and `verified` are both `Literal[False]`; the user-facing Ask experience is M9.

**Every number below was measured over a synthetic corpus written for this repository.** It is not
licensed medical content, no clinician reviewed it, and none of it is evidence about clinical
performance. Where this report says **synthetic engineering benchmark**, that is the complete claim.

Branch `main`, working tree clean at start. Committed baseline **2061000** ("feat: complete M6
CrossEncoder reranking and bounded evidence sets"). Earlier checkpoints **ecb4941** (M5),
**d50521b** (M4), **6cca864** (M3), **0d2085a** (M2), **bb2bfa0** (M1). Focused M6/M5 baseline

## 2. Scope implemented

A typed Evidence Sufficiency Gate that runs between the M6 EvidenceSet and any provider call; a
provider-independent generation layer with OpenAI and Anthropic adapters and a deterministic double;
deterministic citation binding; typed abstention; an authorized draft endpoint; inspector UI for
the three M7 stages; and a measured sufficiency and draft-contract baseline. No relational entity,
no migration, no ingestion-state change, and no change to M5 or M6 semantics.

## 3. Ordering — the safety property

`services/generation.py` runs retrieval → reranking → evidence → **gate** → provider, and the
provider is *constructed after* the decision. There is no path on which a model runs and the gate is
consulted afterwards. `test_insufficient_evidence_abstains_and_calls_no_provider` asserts the
provider double recorded zero calls when the gate refuses.

## 4. Sufficiency policy

`SufficiencyConfig` (`sufficiency-m7-v1`), frozen and fingerprinted. Per-question-kind
`EvidenceRequirement` models rather than one global rule.

| Kind | Requires |
|---|---|
| `ORDINARY_FACTUAL` | ≥1 supporting anchor, ≥1 independent source, ≥1 non-assessment source |
| `TABLE_DEPENDENT` | the above, plus every table part carrying its header rows |
| `FORMULA_DEPENDENT` | the above, plus a FORMULA artifact |
| `FIGURE_DEPENDENT` | the above, plus an approved vision path — which M7 does not have |
| `ASSESSMENT` | a non-assessment source |

Also applied to every kind: budget omissions and partial-span blocks count as missing source, and
retrieval warnings block generation.

## 5. No score is sufficiency

`retrieval_scores_permitted` is `Literal[False]`. No policy field is a float. No lane, fusion or
reranker score is reachable from the gate. Three assertions enforce this:
`test_no_retrieval_or_reranker_score_participates_in_the_decision` checks the field names carry no
threshold or lane vocabulary, that no policy value is a float, and that `gate.py` never references
`reranker_score`, `fused_score`, `dense_score` or `sparse_score`.

M6's observation that the CrossEncoder logit separated its 24 synthetic positives from its negatives
was **not** converted into a threshold. It was an engineering observation on a tiny fixture, and
making it the arbiter of whether a medical answer is allowed is exactly the substitution ADR-012
forbids.

## 6. Decision signals and reason codes

Signals: `supporting_blocks` (ranked anchors only — expansion context supports its anchor and is
not independent support), `independent_sources` (distinct document versions),
`non_assessment_sources`, `authority_levels`, `table_structure`, `formula_source`,
`visual_interpretation`, `budget_omissions`, `incomplete_context_blocks`, `retrieval_warnings`,
`evidence_conflicts`. Each is returned with the requirement it was compared against and whether it
was satisfied.

Reason codes — supporting: `SUPPORTED_BY_SOURCE_EVIDENCE`, `SUPPORTED_BY_INDEPENDENT_SOURCES`,
`SUPPORTED_BY_NON_ASSESSMENT_SOURCE`, `REQUIRED_ARTIFACT_PRESENT`. Insufficiency: `NO_EVIDENCE`,
`INSUFFICIENT_SUPPORTING_BLOCKS`, `INSUFFICIENT_INDEPENDENT_SOURCES`, `ASSESSMENT_ONLY_EVIDENCE`,
`TABLE_STRUCTURE_INCOMPLETE`, `FORMULA_SOURCE_MISSING`, `VISUAL_INTERPRETATION_UNAVAILABLE`,
`EVIDENCE_BUDGET_OMISSION`, `CONTEXT_INCOMPLETE`, `RETRIEVAL_WARNING_PRESENT`. Conflict:
`ASSESSMENT_KEY_UNSUPPORTED_BY_REFERENCE`, `INDEPENDENT_SOURCE_VALUE_CONFLICT`.

The decision carries **no percentage, probability or score**. M7 establishes no calibrated notion of
medical confidence and must not imply one.

## 7. The M6 table and figure gaps become abstentions

M6 finished with measured table and figure context gaps. M7 does not hide them: a table question
whose part lacks header rows returns `TABLE_STRUCTURE_INCOMPLETE`, and a figure question returns
`VISUAL_INTERPRETATION_UNAVAILABLE` in every case, because no vision path is approved and a caption
— or the structural label M3 writes for a captionless figure — records that a figure exists rather
than what it shows. Both adapters refuse `analyze_image`. This was confirmed live: see §14.

## 8. Conflict, not silent selection

Two deterministic detectors, both narrow, both over-triggering by design. An assessment key whose
content the reference evidence in the same set does not support; and two independent non-assessment
document versions stating different values for the same labelled quantity. One document stating
several values for one label is a range, not a disagreement; different labels sharing a unit do not
conflict. Detected conflicts make the status `CONFLICTING`, every competing block is preserved and
returned, and nothing chooses between sources.

Status precedence is `CONFLICTING` > `INSUFFICIENT` > `SUFFICIENT`, and every triggered reason code
from both evaluations is reported regardless, so the precedence hides nothing.

M7 detects disagreement already present in the evidence. It deliberately does **not** implement
claim-level verification of a generated draft.

## 9. Generation boundary

The provider receives the versioned system policy, the question and the rendered EvidenceSet, and
nothing else — no corpus handle, no Qdrant access, no tool, no web search, and no rank or score. The
prompt states *"Pretrained model knowledge is not valid evidence for this answer."* and the same
prohibition is pinned by type. `test_rendered_evidence_carries_identity_and_source_but_no_rank_or_score`
and the integration test that inspects the real rendering both assert the omission; the evaluation
reports `rank_or_score_leaked_to_provider: false`.

The client sends a question and optional filters. `extra="forbid"` rejects `tenant_id`,
`evidence_ids`, `provider`, `model_id`, `system_policy` and `sufficiency` with 422; the frontend
test asserts the request body contains exactly `query` and `mode`.

Output is validated for schema and for citation membership. An id that exists elsewhere is still
unknown here. Rejections: `GENERATION_UNKNOWN_CITATION`, `GENERATION_MISSING_CITATION`,
`GENERATION_SCHEMA_VIOLATION`, `GENERATION_EMPTY`.

## 10. Providers, models and secrets

| Property | Value |
|---|---|
| Protocol | `generation/providers/base.py` — `generate`, `generate_structured`, `analyze_image` |
| Adapters | `openai.py` (JSON-schema response format), `anthropic.py` (one forced tool), `fake.py` |
| Transport | the repository's existing httpx dependency; no vendor SDK added |
| Selection | `MEDRAG_GENERATOR__PROVIDER`, `MEDRAG_GENERATOR__MODEL_ID` |
| Keys | `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`, also accepted `MEDRAG_`-prefixed |
| Attempts / fallback | 1 / `NONE` |
| Temperature | 0.0 |

Isolation is asserted, not assumed: `test_no_vendor_sdk_or_endpoint_leaks_outside_the_adapters`
scans every file under `backend/app` outside `generation/providers/` for a vendor endpoint or
import. **That test caught a real leak during development** — the vendor base URLs had been placed
in `core/generation_config.py`. They now live in their adapters, with the config carrying only
optional overrides for pointing at a test double.

No configured generator means unavailable, not a default model. `max_attempts` is 1 and
`fallback_policy` is `NONE`, because a retry that silently reached a different provider would make
a draft's recorded provenance untrue.

Security checks: no key in Git (`.env` ignored, `.env.example` carries empty placeholders); no key
in the frontend (`test_no_provider_key_reaches_the_frontend_bundle` rejects any `VITE_OPENAI`,
`VITE_ANTHROPIC` or `sk-` in `frontend/src`); no key in any response
(`test_no_provider_key_appears_in_any_response`); provider error bodies are not echoed because they
can quote the prompt back, and `test_provider_http_failures_are_typed_and_fail_closed` asserts the
key does not appear in the raised message. Compose delivers the keys to the **API alone** — not the
dispatcher, worker, retrieval runtime or frontend. The server owns the prompt, evidence, schema and
model, so the endpoint cannot be used as a provider relay.

## 11. Failure behaviour

`GENERATION_NOT_PERMITTED`, `_PROVIDER_UNCONFIGURED`, `_PROVIDER_UNAVAILABLE`, `_PROVIDER_TIMEOUT`,
`_PROVIDER_AUTH_FAILED`, `_RATE_LIMITED`, `_MALFORMED_RESPONSE`, `_SCHEMA_VIOLATION`,
`_UNKNOWN_CITATION`, `_MISSING_CITATION`, `_EMPTY`. Every one abstains. **No path leads from a
failed grounded generation to an ungrounded answer**, and `test_no_provider_falls_back_to_another_provider_or_model`
asserts `services/generation.py` contains no `except GenerationError`.

## 12. Sufficiency evaluation

`scripts/evaluate_sufficiency.py` over `m7-sufficiency-gold-v1`: 14 cases covering all twelve
required categories, with evidence built from the **frozen M5 gold corpus** rather than new content,
so source text, document identity and authority are the ones M5 and M6 were measured against.
Anchors are prescribed, so this measures the gate and not the retrieval feeding it.

| Outcome | Count |
|---|---|
| SUFFICIENT → SUFFICIENT | 4 |
| INSUFFICIENT → INSUFFICIENT | 8 |
| CONFLICTING → CONFLICTING | 2 |

Agreement **1.0000**. Abstention rate **0.7143**. **False allows: 0.** Unnecessary abstentions: 0.

Every case also abstained for the *correct specific* reason, not by luck: `s-table-missing-headers`
on `TABLE_STRUCTURE_INCOMPLETE`, `s-figure-visual-required` on `VISUAL_INTERPRETATION_UNAVAILABLE`,
`s-assessment-only` on `ASSESSMENT_ONLY_EVIDENCE`, `s-budget-omission` on
`EVIDENCE_BUDGET_OMISSION`, `s-incomplete-fragment` on `CONTEXT_INCOMPLETE`,
`s-authoritative-conflict` on `INDEPENDENT_SOURCE_VALUE_CONFLICT`, `s-assessment-vs-reference` on
`ASSESSMENT_KEY_UNSUPPORTED_BY_REFERENCE`.

**This 100% is weak evidence and is not offered as a quality claim.** Fourteen cases were written
alongside the gate that decides them, by the same author, in the same session. It demonstrates that
the implemented rules do what they were designed to do on the cases they were designed for. It
establishes nothing about unseen questions, and nothing whatsoever clinically. The gate is not
calibrated and no threshold in it is measured.

## 13. Generation evaluation

Generation attempted on 4 of 14 cases, suppressed on 10 — the suppression tracks the gate exactly.
Schema validity 1.0; citation validity 1.0; invented-citation rejection 1.0; evidence-id
hallucination rate 0.0; `rank_or_score_leaked_to_provider` false.

These measure the contract M7 enforces. **Answer correctness and claim entailment are not measured
and are not claimed** — they are M8/M11.

## 16. Defects found and fixed

### Found by the live provider smoke (after M7 was committed)

**The adapter sent `temperature: 0.0` on every request, and the configured model rejects it**
(`400 invalid_request_error / unsupported_value / temperature` — only the model's default is
supported). Every live call failed. Removing the field returned 200. `temperature` is now omitted
unless explicitly configured, and `ProviderSpec.temperature` is `None` when the provider's default
was used — because the trace records what actually reached the provider, and a temperature that was
never sent must not be written into a draft's provenance. A temperature setting never guaranteed
determinism in any case.

**A 4xx was classified as `GENERATION_PROVIDER_UNAVAILABLE`.** That is misleading: a rejected
request is not an outage, and the label would send whoever reads the log hunting a down provider
instead of a malformed field. It is now `GENERATION_PROVIDER_REJECTED_REQUEST`, carrying only the
provider's machine-readable `code` and `param` — never its prose, which can echo the prompt. Had
this existed first, the temperature failure would have been self-diagnosing.

**`.env.example:38` documented a value that could not be loaded.** `MEDRAG_RERANKER__OFFLINE=true`
against `offline: Literal[True]` — an environment variable arrives as a string and `Literal[True]`
does not coerce one, so copying that block into `.env` broke *every* `Settings()` construction on
the host. Pre-existing M6 defect, committed at HEAD, unrelated to M7, and surfaced only because the
documented block was copied in while configuring the generator. The string form is now accepted and
the pin still holds: the reranker cannot be taken out of local-only mode. The sibling
`QueryEncoderConfig.offline` and `EmbeddingConfig.offline` are plain `bool` and were never affected.

**`test_config.py` asserted `settings.generator is None`** — an M0-era assumption that no provider
would ever be configured, which stopped being true the moment one was. It now controls its own
environment rather than depending on the deployment's, with a companion test asserting that a
configured generator parses and that its key stays out of `repr` and `model_dump_json`.

### Found during M7 development



**The API container would not start when a generator variable was declared but empty.** Compose
passes a declared variable through as `""`, so `MEDRAG_GENERATOR__PROVIDER=` arrived as
`{"provider": "", "model_id": ""}` and failed `ModelSelection` validation, taking down the whole
API — for the sole reason that no provider account was configured. A `field_validator` now treats an
all-empty selection as unconfigured. Covered by
`test_a_declared_but_empty_generator_variable_leaves_generation_unconfigured`.

An earlier host check appeared to show this was safe; that check was invalid, because PowerShell's
`$env:X=""` removes the variable rather than setting it empty, so it never reproduced the
container's condition. The container log is what found it.

**Vendor base URLs sat in `core/generation_config.py`,** outside the adapters, which is the boundary
ADR-005 exists to hold. Found by the isolation test that was written to catch exactly this. Moved
into the adapters.

**The sufficiency signals table overflowed a 390 px viewport,** scrolling the page body instead of
itself. The application already has a `.table-scroll` convention that I had not used. Found by the
browser test.

## 17. Known limitations

- **Synthetic engineering benchmark, not clinical validation.** 14 gate cases and a 83-chunk corpus,
  no clinician annotation.
- **The gold cases were written alongside the gate they measure.** 100% agreement demonstrates
  internal consistency, not generalization.
- **Nothing in the gate is calibrated.** Minimum block and source counts are conservative starting
  points, not measured optima. No held-out evaluation exists.
- The conflict detectors over-trigger by design and will produce false conflicts where a shared
  label and unit coincide across documents. That costs coverage and is not tuned away.
- Conflict detection is value-level and key-level only. Two sources contradicting each other in
  prose, with no differing labelled quantity and no assessment key, are not detected.
- Every figure-dependent question abstains. That is correct today and remains a coverage gap.
- Abstention rate on the fixture is 0.71. Coverage is deliberately traded for safety.
- **Only OpenAI has been exercised live**, once, on one question. The Anthropic adapter is
  verified against a mocked transport only. One passing call is not a measurement of provider
  reliability, latency distribution or output quality.
- Answer correctness, claim entailment and citation *support* are not measured. A grounded draft is
  unverified output awaiting M8.
- **M8 has not started.**

## 18. Definition of done

Gate executes before generation; the three statuses are explicit; no single score is treated as
sufficiency; generation occurs only when policy permits; insufficient evidence abstains; conflicts
are preserved rather than resolved; source authority participates; the provider abstraction exists
with two isolated adapters; provider and model are configuration-driven; keys are backend-only and
none is committed; the generator receives only EvidenceSet-grounded input; pretrained knowledge is
prohibited in prompt and policy; citations must belong to the supplied set; invalid provider output
fails closed; provider failure never falls back to ungrounded answering; tenant and corpus
authorization stay server-side; M5 and M6 semantics are unchanged; the evaluation and this report
exist; `AI_HANDOFF.md` is updated; the final Ask experience remains disabled; **M8 claim
verification has NOT been implemented.**
